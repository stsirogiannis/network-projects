# Network Projects
 
A collection of network design and configuration projects built in Cisco Packet Tracer, covering routing, security, and network services.
 
## Projects
 
| Project | Summary |
|---|---|
| [Zone-Based Policy Firewall](./zone-based-policy-firewall) | Converts a router into a stateful firewall using ZPF — zones, class-maps, and policy-maps to control traffic to/from a protected server. |
| [School Network Access Control](./acl-school-network) | Segments a school network with OSPF routing and Extended ACLs so Students and Teachers can each reach only their own server. |
 
*(More projects added as they're completed.)*
 
## Tools Used
 
- [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer)
## About
 
Each project folder contains its own README with a network diagram, configuration walkthrough, and the downloadable `.pkt` file — open it directly in Packet Tracer to explore the topology and device configs.
